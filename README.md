# High Cloud Airlines Analysis

## Project Overview
 This project analyzes High Cloud Airlines data to derive business insights using Excel, SQL, Power BI, and Tableau.
- Excel
- SQL
- Power BI
- Tableau

## Tools Used
- Excel (Data cleaning & analysis)
- SQL (Querying insights)
- Power BI (Interactive dashboard)
- Tableau (Visual analysis)

## Files Included
- Power BI dashboard (.pbix)
- Tableau workbook (.twbx)
- SQL queries (.sql)
- Final presentation (.pptx)

## Key Insights
- Top performing sectors
- Portfolio value analysis
- Revenue and performance trends
